# 🌿 WildSketch — Майстер-класи з малювання на природі

**WildSketch** — це командний вебпроєкт, створений для популяризації малювання на природі. Він поєднує мистецтво, творчість і природу, пропонуючи користувачам можливість розвивати свої художні навички під час творчих занять просто неба.

## 👥 Про проєкт

WildSketch — це результат командної роботи, спрямованої на створення сучасного, зручного та візуально привабливого вебсайту. Під час роботи над проєктом учасники команди співпрацювали над реалізацією дизайну, структури та функціональності сайту.
